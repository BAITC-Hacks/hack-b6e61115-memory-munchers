# HACKALEM AI — ИИ-ассистент для чата ekt.kz

Источник — кейс ТОО «Электрокомплект», предоставленный Адилем 23.09.2026. Основной интерфейс — единое окно чата на сайте (desktop/mobile); Telegram дополнительный.

Проблема: покупателю приходится обращаться к менеджеру ради характеристик, наличия, аналогов и условий. Решение сокращает путь от вопроса к подтверждённому составу корзины.

## Must-have

1. Существующий артикул: верное наличие, характеристики, сертификат при наличии в базе.
2. Нулевой остаток: минимум один релевантный аналог с кратким обоснованием.
3. Содержательный ответ про оплату, доставку и минимальную партию.
4. Без явного «да, добавь» корзина не меняется; после согласия количество не превышает остаток.
5. Прямая ссылка на актуальную корзину/оформление после добавления.

Вход: текст и контекст сессии, Excel, Word, PDF, JPEG; каталог с ценой и остатками по складам. Для прототипа допускается репрезентативная синтетическая или анонимизированная выборка. Здесь используется выгрузка EKT.

Нельзя менять корзину/оформлять без согласия, выдумывать цену/наличие, запрашивать/хранить платёжные данные. Нужны приватность, защита корзины, объяснимые аналоги, совместимость с платформой и desktop/mobile; ответ за единицы секунд.

Опционально: казахский, сопутствующие товары, авторизованная история, эскалация менеджеру. Артефакты: репозиторий, README с архитектурой, запуском и данными.

Статус каждого условия и границы прототипа: [HACKALEM_COMPLIANCE.md](HACKALEM_COMPLIANCE.md). Корзина локальная; официальный bridge checkout партнёром не предоставлен. Production EKT не изменяется.
