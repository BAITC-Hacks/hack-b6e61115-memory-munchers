# Проверка по кейсу HACKALEM AI

23.09.2026. Объект — Python-версия в корне alternative_version; прежняя .NET-версия не входит в аудит. Источник требований — полный кейс ekt.kz, предоставленный Адилем. Production не изменялся.

## Пять must-have

1. **Каталог/наличие/характеристики/сертификаты: реализовано для доступных данных.** `app/catalog.py`, `app/agent.py:87` формируют ответ из каталога и показывают источник остатка. `tests/test_catalog.py` проверяет реальный артикул и документы. Внутренний file ID не превращается в вымышленный URL; явный запрос сертификата использует resolver. Снимок не выдаётся за текущий остаток.
2. **Аналоги: реализовано.** `app/catalog.py:360` сравнивает параметры и объясняет различия. При аудите исправлен модельный путь: сервер добавляет аналог после поиска позиции с нулевым остатком (`app/agent.py:485`, регрессия `test_model_search_for_zero_stock_gets_server_selected_alternative`). При отсутствии доказанного аналога возвращается честный отказ; покрытие зависит от семейства товаров.
3. **Условия покупки: сохранённая содержательная справка.** `app/terms.py` содержит оплату, доставку, неизвестный общий минимум и источник. Тесты подтверждают содержание, но повторная актуальность условий магазина в этой сессии не подтверждена: страницы EKT через web-инструмент недоступны.
4. **Согласие/количество/остатки: реализовано для локальной корзины.** `app/main.py`, `Assistant.confirm`, `app/store.py:231`: точное согласие, владелец, срок предложения, повтор, свежесть/цена, агрегированное количество и атомарная запись. Тесты: `tests/test_store.py`, `tests/test_agent.py`, `tests/test_integration.py`. Очистка тоже теперь требует `Да, очистить корзину` на сервере. Без EKT доступа подтверждение отклоняется, корзина сохраняется.
5. **Прямая ссылка: есть для корзины прототипа.** `/cart/{token}` читает актуальную SQLite, не кешируется. `test_draft_confirm_link_memory_and_repeat_requires_new_consent` проверяет ссылку и повтор. **Если нужен именно production checkout ekt.kz — критерий закрыт частично:** официального cart/session bridge нет, резервирование/оплата не реализованы.

## Остальные условия

- Один чат на сайте и инструменты агента реализованы; сервер отдельно контролирует корзину. Desktop 1280×720 и мобильная ширина 390×844 проверены в браузере. Запрос артикула показал характеристики, четыре сертификата и trace product_details; корзина осталась пустой.
- XLSX/DOCX/текстовый PDF/JPEG/PNG поддержаны, 15 МиБ максимум, частичное извлечение явно отмечается. XLS/DOC требуют пересохранения, скан PDF — фото. Проверки `tests/test_attachments.py` и HTTP `tests/test_web.py`; реальное распознавание фото моделью в текущем аудите не запускалось.
- Сессия: HttpOnly/SameSite cookie, проверка владельца, случайный токен, ограниченная история. Приватные API теперь no-store/no-referrer. Ссылка корзины является ссылкой доступа: знающий токен может посмотреть состав. Полная политика хранения и удаления для production отсутствует.
- **Платёжные данные: открытый пробел.** Формы оплаты нет, SYSTEM запрещает запрашивать/повторять реквизиты. Но произвольный текст истории сохраняется, автоматического удаления таких данных нет. Требование «не хранить» нельзя считать полностью выполненным.
- Скорость: бюджеты 7,2/7,6 секунды и fallback; это не гарантия полного успешного ответа. Live-LLM замеры текущей версии не проводились. Старые замеры отдельно в PERFORMANCE_CORE.md.
- Совместимость с платформой production EKT не проверена. Казахский и реальная передача менеджеру не завершены. История относится к локальным подборам, не оплаченной истории EKT.
- README, архитектура, описание данных, Docker и тесты подготовлены. Codex использован. Состав команды/дедлайн/форма сдачи не проверяются кодом.

## Исправления аудита

Серверное согласие очистки; no-store приватных API; ограничение подписи вложения; аналоги в модельном пути; разрешение сертификатов; понятный атомарный отказ при исключении сервиса остатков; честный ответ при отсутствии аналога. Smoke больше не читает `.env.railway` автоматически.
