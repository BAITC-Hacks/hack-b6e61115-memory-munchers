# Интеграция EKT: сайт, ассистент и управление

Дата: 23.09.2026. Владелец: Адиль / QazSight. Существующий OpenAI-ключ повторно используется по подтверждению в сессии ядра.

## Источники и границы ответственности

- `дизайн/index.html`, `дизайн/DESIGN-AUDIT.md`: макет магазина и аудит демо-логики. Демо engine не используется как backend.
- `app/agent.py`, `app/catalog.py`, `app/store.py`: общее ядро сайта и Telegram. Сессия «Создай Telegram-бота для EKT» продолжает качество и стоимость.
- Интеграционная сессия: сайт, HTTP-контракты, CMS департаментов, экспорт, сквозные проверки.
- Каталог — реальная выгрузка EKT; изменения остатков/цен магазина не выполняются. Подтверждение перепроверяет живой остаток.
- Текущая корзина — серверная корзина ассистента. API переноса в checkout EKT и исторические заказы EKT партнёром пока не предоставлены.

## Приёмка исходного запроса

1. Точный артикул возвращает товар, остаток, характеристики и существующие сертификаты.
2. Нулевая позиция получает релевантные аналоги с причиной и ограничениями совместимости.
3. Оплата, доставка, минимальная партия — из проверенных условий, неизвестные значения не придуманы.
4. Предложение полного состава не изменяет корзину. Только явное подтверждение, с проверкой количества, цены и остатков.
5. Ссылка открывает актуальную серверную корзину. Внешний checkout подключается только при наличии рабочего контракта.
6. Свободный диалог + workflow, память сессии/подборов, вложения Excel/Word/PDF/JPEG, протокол менеджера и технический web search.
7. Иерархия отделов, задачи, мониторинг, редактируемые тексты сайта, выгрузки Excel/PDF из реальных данных.
8. Замеры скорости и качества, воспроизводимый запуск, полный TODO и README.

## Подтверждённый начальный замер

- `data/baseline_http.json`: три GET карточки EKT, HTTP 200, 0.175–0.207 с.
- `data/benchmark_direct_model_baseline.json`: два прямых ответа o1-pro, 46.961 и 36.392 с; это генерация по карточке, не полный диалог агента.
- Требование «единицы секунд» нельзя объявить выполненным для o1-pro. Точные артикулы, условия и подтверждение идут по серверному маршруту без LLM.

## Выпуск

Проверяется локальная сборка. Публикация в живой ekt.kz требует доступа к размещению и явного разрешения владельца. Модель, токены и настройки существующего Telegram не заменяются интегратором.
